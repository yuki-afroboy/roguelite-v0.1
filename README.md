# 縫夜 -NUIYO-

**指でなぞった光の糸が、閉じた瞬間に武器になる。**
スマホのブラウザで、片手で遊ぶ2Dローグライト。

```
夜は綻び、綻びからは獣が滴る。
お前の指先だけが、まだ光の糸を引ける。
```

---

## 遊ぶ

```bash
npm start          # http://localhost:5173/
```

同じ Wi-Fi なら `http://<PCのIP>:5173/` でスマホから直接遊べます。

```bash
npm run build      # dist/nuiyo.html （全部入り1枚。ダブルクリックで動く）
```

依存パッケージはゼロ。画像も音声ファイルも1つも読み込みません（すべて実行時生成）。

## 核となる仕組み ── 「縫（ぬい）」

このゲームには攻撃ボタンがありません。**移動そのものが攻撃**です。

1. 走った跡には光の糸が残る（長さは有限。走り続けると尾から消えていく）
2. 糸が **自分自身と交わって輪が閉じた瞬間**、その **内側にいた獣が全て縫い落とされる**
3. **広く囲むほど威力が上がり、続けざまに閉じるほど連鎖倍率が乗る**

この一点から、要求されていた3つが同時に立ち上がります。

| 要求 | この仕組みがどう満たすか |
|---|---|
| 片手操作 | 入力は「指を滑らせる」だけ。狙う・撃つ・避けるが全部その1操作に統合される |
| 大量の敵を倒す爽快感 | 敵が多いほど輪の中身が増える。数がそのまま快感に変換される |
| 1プレイ10分 | 敵密度と糸の長さの綱引きが、そのまま難度曲線になる |

### 設計上、意図して作った緊張

- **大きく囲むほど、糸を多く食う。** 輪になった部分は糸から切り離されるので、大物狙いの直後は丸腰。走って糸を張り直すまでが「隙」になります。
- **敵はプレイヤーより遅いが、確実に追ってくる。** 走れば背後に必ず尾が引かれる。その尾を巻き取るのが基本の立ち回りです。
- **連鎖は一気に0へ落ちない。** 途切れると1段ずつ冷めていく。指1本で遊ぶ相手に「全部失う」罰は重すぎる、という判断です。
- **「あと少しで閉じる」は閉じたことにする。** 厳密な交差判定だけだと、大きく回り込んで数px届かなかったときに何も起きず、操作が死んだように感じます（実際に試して確認しました）。24px以内まで近づいたら線分上の最近点にスナップして閉じます。手触りはここで決まっています。
- **閉じ口を常に見せる。** 針が自分の糸に近づくと、閉じる先までの破線と、囲われる領域が浮かびます。「触れると何かが起きる」を文章ではなく画面で教えるための線です。
- **ただ触れているだけでは痛くない。** 囲むには群れの中へ戻る必要があり、群れは常に寄ってくる ── 回り込む動線上に体が置かれるのは機構が持つ幾何で、間合いを調整しても消えません。そこで基本種の接触は押しのけて通し、痛いのは跳びかかってきた個体・精鋭・専門種だけにしています。
- **湧きは速度ではなく密度で管理する。** 「1秒に何体」ではなく「同時に何体いてほしいか」を目標にして差分だけ湧かせます。倒し遅れた人には自動的に猶予が生まれ、画面が敵で埋まって立て直せなくなる状態を作りません。
- **糸を編み直すたび、綻びも1つ繕われる。** レベルアップで HP が1回復します。10分の運びに対して回復手段が無いと、数回の被弾で終わってしまうためです。

## ゲーム構成

**夜（ステージ）に挑み、持ち帰ったもので恒久的に鍛え、また次の夜へ。**

```
拠点 → 夜を選ぶ → 戦闘（レベルアップで札を選ぶ）→ 結果・報酬 → 拠点 → 織機／装い → 次の夜
```

### 第一章 五つの夜

| 夜 | 名前 | 長さ | 出る獣 | 教えること |
|---|---|---|---|---|
| 1 | 初めの綻び | 2:30 | 綻 | 囲めば落ちる |
| 2 | 群れる夜 | 3:30 | ＋疾 | 大きく囲むほど多く落ちる |
| 3 | 裂ける夜 | 3:45 | ＋裂 | 分裂を見越して二度縫う |
| 4 | 間合いの夜 | 4:00 | ＋咎・鎧 | 弾は糸の先で払える |
| 5 | 織主・綻 | 5:00 | 全種＋**織主** | 硬い相手は一縫では落ちない |

難度は敵HPの水増しではなく、**敵構成・同時に居る数・夜の長さ**で作っています。
「同時に画面にいる数」と「倒せる総数」は別のつまみで、前者を抑えたまま後者だけ増やせます。

### 恒久成長 ── 織機

光糸を払って12ノードを鍛えます。設計の背骨は一つ。

> **恒久強化で買えるのは「生存」と「可能性」、そして「上手さへの見返り」。**
> **火力は最後まで、輪の大きさと連鎖 ── つまり腕から出る。**

| 枝 | 役割 | ノード |
|---|---|---|
| **糸** | 何が可能になるか | 糸の長さ／閉じ寄せ |
| **針** | 生き延びる力 | 最大HP／無敵時間／移動速度 |
| **環** | 上手さへの見返り | 面積補正／連鎖の猶予・上限／**縫撃威力(上限+25%)**／解きの初期充填／光の実り／吸引 |

各ノードの上位Rankは**綻び核**で段階的に開きます。第一章で買えるのは各ノードRank2まで。

### 装備 ── 針・糸・環

数値の棒ではなく、**縫い方が変わる**ものだけを置いています。

| | |
|---|---|
| **霞糸** | 糸 −25% / 閉じる距離 2.5倍 → 小さく速い輪を連ねる |
| **大縄** | 糸 +35% / 速度 −8% → 一度に大きく巻き取る |
| **灼針** | 針先が灼く。ただし、ひるみで押し退けられなくなる |
| **双環** | 縫った瞬間、自分の周りにも輪が生まれる |

霧の露で編み、夜を突破すると設計図が開きます。

### 光と光糸

拾うものは2種類あり、**色も形も音も分けて**あります。

- **光**（青い菱形）── その夜のレベルが上がる。持ち帰れない
- **光糸**（金の糸巻き）── 恒久通貨。**拾った分は負けても持ち帰る**

踏破の報い（固定の光糸）はクリア時のみ、綻び核と次の夜の解放は初回クリアのみです。

### 解（ほど）き

縫い落とした数でゲージが溜まります。満ちたら **画面を短く叩く**（ドラッグではなく1回タップ）。
夜が裂けて全方位に光が走り、**世界だけが 0.22 倍速に落ちて、自分はそのまま**。糸を引き直す猶予です。

## 技術

**Canvas 2D + 素の ES Modules。ビルド不要、依存ゼロ、アセット0バイト。**

初見で触ってもらうゲームでロード待ちは致命的なので、絵も音も実行時生成に振り切りました。

- **音** ── WebAudio のオシレータとノイズバッファのみ。輪を閉じる音は連鎖数で音階が駆け上がり、BGMは敵密度と経過時間で密度が上がる8ステップのシーケンサ
- **絵** ── 獣は起動時にオフスクリーンcanvasへ焼き、以後は `drawImage` のみ。数百体を描くので `save/restore` と `rotate` は使わず行列を直接差し替え
- **当たり** ── 一様グリッドで空間分割。輪の判定は外接矩形でセルを引いてから点内包判定
- **糸** ── 7px 等間隔にリサンプリングした節列。節を打つたびに最新線分と過去の全線分を照合し、**最も古い交わり＝最大の輪**を採用

計測（headless Chromium / ソフトウェアラスタライズ、実機GPUより不利な条件）で、敵450体同時でも描画が破綻しないことを確認しています。実機では60fps想定。

## 手触りの検証について

操作モデルを3種類（仕組みを知らず彷徨う人／「回れば閉じる」と気付いたが糸の長さを知らない人／
糸が届く半径で群れを回り込む人）作り、ヘッドレスブラウザで同じ操作を新旧の実装にぶつけて比較しています。
`tools/` には含めていませんが、生存時間・初回の輪までの秒数・到達レベル・被弾の内訳・
同時敵数の推移を測ると、体感に頼らずに調整できます。

なお「閉じ口の可視化」だけは操作モデルでは測れません（機械は画面を見ないため）。
ここは実際に描画して目視で確認する必要があります。

## 既知の割り切り

- スコアと最高記録は `localStorage`。プライベートモードでは保存されませんが、プレイには影響しません
- 実機での指の感触（スナップ距離24px、糸の長さ910px）は自動テストでは詰め切れない領域です。触ってみて重い・軽いがあれば `src/thread.js` の `SNAP` と `src/upgrades.js` の `threadPts` が効きます
