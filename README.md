# 縫夜 -NUIYO-

**指でなぞった光の糸が、閉じた瞬間に武器になる。**
スマホのブラウザで、片手で、10分で終わる2Dローグライト。

```
夜は綻び、綻びからは獣が滴る。
お前の指先だけが、まだ光の糸を引ける。
```

---

## 遊ぶ

```bash
npm start          # http://localhost:5173/
```

同じ Wi-Fi なら `http://<PCのIP>:5173/` でスマホから直接遊べます。

```bash
npm run build      # dist/nuiyo.html （全部入り1枚。ダブルクリックで動く）
```

依存パッケージはゼロ。画像も音声ファイルも1つも読み込みません（すべて実行時生成）。

## 核となる仕組み ── 「縫（ぬい）」

このゲームには攻撃ボタンがありません。**移動そのものが攻撃**です。

1. 走った跡には光の糸が残る（長さは有限。走り続けると尾から消えていく）
2. 糸が **自分自身と交わって輪が閉じた瞬間**、その **内側にいた獣が全て縫い落とされる**
3. **広く囲むほど威力が上がり、続けざまに閉じるほど連鎖倍率が乗る**

この一点から、要求されていた3つが同時に立ち上がります。

| 要求 | この仕組みがどう満たすか |
|---|---|
| 片手操作 | 入力は「指を滑らせる」だけ。狙う・撃つ・避けるが全部その1操作に統合される |
| 大量の敵を倒す爽快感 | 敵が多いほど輪の中身が増える。数がそのまま快感に変換される |
| 1プレイ10分 | 敵密度と糸の長さの綱引きが、そのまま難度曲線になる |

### 設計上、意図して作った緊張

- **大きく囲むほど、糸を多く食う。** 輪になった部分は糸から切り離されるので、大物狙いの直後は丸腰。走って糸を張り直すまでが「隙」になります。
- **敵はプレイヤーより遅いが、確実に追ってくる。** 走れば背後に必ず尾が引かれる。その尾を巻き取るのが基本の立ち回りです。
- **連鎖は一気に0へ落ちない。** 途切れると1段ずつ冷めていく。指1本で遊ぶ相手に「全部失う」罰は重すぎる、という判断です。
- **「あと少しで閉じる」は閉じたことにする。** 厳密な交差判定だけだと、大きく回り込んで数px届かなかったときに何も起きず、操作が死んだように感じます（実際に試して確認しました）。24px以内まで近づいたら線分上の最近点にスナップして閉じます。手触りはここで決まっています。

## ゲーム構成

**10分・1本勝負。** 織主（ボス）を縫い切れば夜明け、HPが尽きれば綻び。

| 時刻 | 起こること |
|---|---|
| 0:00 | 綻（基本の群れ）のみ |
| 0:50 | 疾（突進） |
| 2:15 | 裂（倒すと3体に分かれる） |
| 3:25 | 咎（遠距離） |
| 4:30 | **織主 出現** |
| 5:20 | 鎧（防御。貫穿がないと硬い） |
| 8:30 | **織主・終** ─ 倒せば勝ち |

22秒ごとに湧きの脈（サージ）が来て、群れが一気に濃くなります。囲むなら、ここ。

### 縫い型（開始時に選ぶ）

| | |
|---|---|
| **疾型** | 速いが糸は短い。小さく速い輪で連鎖を稼ぐ |
| **長型** | 糸は長いが鈍い。一度に大量を巻き取る |
| **鋭型** | 威力1.45倍・針先に熱を持つがHP-2 |

### 成長

光（経験値）を集めてレベルアップ、3枚から1枚を選ぶ。全19種＋取り切った後の繰り返し札。

数値強化（長糸・鋭刃・疾走…）に加えて、**輪の意味そのものを変える札**を混ぜています。

- **残響** ── 0.5秒後、同じ形の輪がもう一度縫われる
- **灼痕** ── 縫った領域が燃え続ける
- **波紋** ── 輪の外側へ衝撃波が走る
- **双環** ── 縫った瞬間、自分の周りにも輪が生まれる
- **誘蛾** ── 獣が逸り、群れが密になる（＝1回の輪の収穫が増える）
- **停時** ── 領域内の生き残りを止める

### 解（ほど）き

縫い落とした数でゲージが溜まります。満ちたら **画面を短く叩く**（ドラッグではなく1回タップ）。
夜が裂けて全方位に光が走り、**世界だけが 0.22 倍速に落ちて、自分はそのまま**。糸を引き直す猶予です。

## 技術

**Canvas 2D + 素の ES Modules。ビルド不要、依存ゼロ、アセット0バイト。**

初見で触ってもらうゲームでロード待ちは致命的なので、絵も音も実行時生成に振り切りました。

- **音** ── WebAudio のオシレータとノイズバッファのみ。輪を閉じる音は連鎖数で音階が駆け上がり、BGMは敵密度と経過時間で密度が上がる8ステップのシーケンサ
- **絵** ── 獣は起動時にオフスクリーンcanvasへ焼き、以後は `drawImage` のみ。数百体を描くので `save/restore` と `rotate` は使わず行列を直接差し替え
- **当たり** ── 一様グリッドで空間分割。輪の判定は外接矩形でセルを引いてから点内包判定
- **糸** ── 7px 等間隔にリサンプリングした節列。節を打つたびに最新線分と過去の全線分を照合し、**最も古い交わり＝最大の輪**を採用

計測（headless Chromium / ソフトウェアラスタライズ、実機GPUより不利な条件）で、敵450体同時でも描画が破綻しないことを確認しています。実機では60fps想定。

## 既知の割り切り

- スコアと最高記録は `localStorage`。プライベートモードでは保存されませんが、プレイには影響しません
- 実機での指の感触（スナップ距離24px、糸の長さ910px）は自動テストでは詰め切れない領域です。触ってみて重い・軽いがあれば `src/thread.js` の `SNAP` と `src/upgrades.js` の `threadPts` が効きます
